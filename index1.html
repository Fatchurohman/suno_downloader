1. Suno Multi-Song Scanner (Bulk MP3)

Tempelkan banyak link lagu Suno sekaligus di bawah ini. Aplikasi akan mendata semua lagu beserta player dan tombol download MP3 penuhnya.

2. Script Bookmarklet (Untuk Halaman Suno di Chrome HP)

Pasang script satu baris ini di Bookmark Chrome HP untuk memindai semua lagu yang tampil di halaman Library suno.com saat kamu login:

  1. Klik tombol Salin Script Bookmarklet di bawah.
  2. Buat Bookmark bebas di Chrome HP, lalu edit bagian URL-nya dan tempel script ini (beri nama misal: SunoDL).
  3. Buka suno.com (posisi Sign-In di Library), ketik SunoDL di bar alamat atas, lalu klik bookmark yang muncul.
